# 猫国建设者本地版：从开局到多周目的玩法攻略

本攻略对应本地原版 **1.6.1.11**。前半部分适合首次游玩，后半部分包含宗教、太空与转生机制。具体数值来自本地源码；行动顺序是便于理解和稳步发展的建议，不是最快通关路线。挑战、政策和多周目奖励会改变很多判断。

如果当前主要困惑是“下一项科技应该研究什么”，先看 [科技树发展路线](科技树发展路线.md)，里面把前置关系、推荐顺序和配套建设放在了一起。

## 1. 你在经营什么

你从猫薄荷森林里的一只小猫开始，逐渐建造田地、住房和生产设施，让猫咪成为农民、伐木工、学者、矿工和猎人。科技解锁更复杂的生产链，随后发展贸易、宗教、工业和太空探索。多周目则把部分成长转成长期奖励，让下一次文明发展更快。

核心循环是：**生产资源 → 扩大仓储 → 建造设施和研究科技 → 解锁新的资源与倍率 → 解决下一层瓶颈。**

每次准备购买前，先确定它解决什么问题：缺稳定产量、缺存储容量、缺解锁条件，还是缺加工效率。看见按钮亮了就买，容易把最需要的原料花掉。

## 2. 先认识界面

| 区域 | 主要用途 | 建议观察的内容 |
| --- | --- | --- |
| 资源面板 | 当前数量、容量、净增减 | 数字是否封顶、每秒产出是否为负 |
| 营火 | 建筑与基础操作 | 悬停查看费用、效果和是否消耗原料 |
| 村庄 | 分配职业、管理猫咪 | 粮食能否支撑人口，幸福度是否下降 |
| 科学 | 研究科技、后续选择政策 | 新科技具体解锁什么 |
| 工坊 | 工具升级、配方与合成 | 是否有能直接改善当前瓶颈的升级 |
| 贸易、宗教、太空、时间 | 随进度开放的系统 | 新的资源来源、倍率和长期发展目标 |
| 日志与队列 | 事件、操作反馈、待办建设 | 天文事件、资源短缺和队列阻塞 |
| 右下角存档管理 | 本地保存、导出、恢复 | 操作后是否显示已保存到磁盘 |

窄窗口下资源、建筑和日志会上下排列，向下滚动即可找到后面的区域。没有出现的页签通常还未解锁。

## 3. 第一阶段：从猫薄荷到稳定人口

### 3.1 先建立不依赖点击的食物来源

1. 点击“采集猫薄荷”，攒够第一块猫薄荷田的费用。
2. 第一块田基础费用为 **10 猫薄荷**，建成后开始持续生产。
3. 继续补田，逐步积累猫薄荷；先留食物余量，再把多余部分精炼成木材。
4. 初始精炼配方为 **100 猫薄荷 → 1 木材**。后续“高级精炼”升级会把猫薄荷费用改为 50。

开局春天一块田约产 0.94 猫薄荷/秒，很容易让人高估它的全年供给能力。普通冬天同一块田在没有其他加成时约产 0.15625/秒，寒冷天气还会更低。

### 3.2 建小屋以前，先考虑多出来的嘴

第一座小屋基础费用为 **5 木材**，增加 **2 个猫咪容量**。有容量后猫咪逐步迁入，小屋本身不会立即送来两名工人。

每只猫未修正的基础消耗为 `0.85 猫薄荷/tick`，普通速度下相当于 **4.25/秒**。实际消耗还受其他机制影响，所以应以面板净产出和冬季表现判断。

小屋价格增长倍率为 2.5，早期连续堆小屋会很快变贵。新增猫咪会增加劳动力，也会增加耗粮。补人口和补供给最好交替进行。

刚有猫咪时可以安排伐木工，让木材有稳定来源。农业解锁前尚不能安排农民，要给田地和粮食储备留足空间。

### 3.3 建图书馆，安排学者，尽早解锁农业

第一座普通图书馆基础费用为 **25 木材**，会开放科学页签和学者职业。图书馆提供科学相关加成和容量；科学的早期持续来源主要是安排学者。

优先理解这两项：

| 科技 | 基础科学费用 | 关键解锁 |
| --- | --- | --- |
| 历法 `calendar` | 30 | 开启后续农业科技路径，提供更完整的时间发展入口 |
| 农业 `agriculture` | 100 | 农民、谷仓，并继续开放采矿和射箭路径 |

农业后，遇到食物压力可调一部分猫咪当农民。农民基础生产为每 tick 1 猫薄荷，在幸福度、工具等修正后提供实际产出。农民与田地的季节计算不同，是早期过冬的重要支撑。

**达到的目标：有自动田地、稳定木材、科学来源，并能通过分工保证猫咪生存。**

## 4. 冬天怎么过

田地的基础季节倍率为：

| 季节 | 田地基础生产倍率 |
| --- | --- |
| 春 | 1.5 |
| 夏 | 1.0 |
| 秋 | 1.0 |
| 冬 | 0.25 |

普通天气基础上，温暖天气使倍率加 0.15，寒冷天气减 0.15。普通冷冬的田地倍率可低至 0.10。这些数字针对基础季节部分，不能直接乘整条猫薄荷净产出来计算。

实用处理顺序：

1. 春夏积粮，冬季前暂缓快速增加人口。
2. 农业后准备足够农民；入冬看到净产出变负，及时调配岗位。
3. 缺粮时先停止把猫薄荷精炼成木材，避免把口粮加工掉。
4. 谷仓提高粮食储备能力，牧场降低需求，后续水渠提高产出；按当前瓶颈选择。
5. 粮食见底会导致猫咪死亡。人口刚好能撑过普通冬天，并不代表也能撑过冷冬。

正常速度下，默认 5 tick/秒、10 tick/日、100 日/季，一季约 200 秒。作为粗略估算，如果确认整个冬季净缺粮为 10/秒，需要约 2000 储粮，再额外留天气和操作余量。生产和人口持续变化时，应重新估算。

## 5. 第二阶段：矿物、工坊与第一条工业链

### 5.1 采矿、射箭和畜牧各解决什么

农业之后可按当前问题选择：

| 科技 | 基础科学费用 | 主要帮助 |
| --- | --- | --- |
| 射箭 `archery` | 300 | 解锁猎人，并通向畜牧 |
| 采矿 `mining` | 500 | 解锁矿井与工坊，并通向金属加工 |
| 金属加工 `metal` | 900 | 解锁冶炼厂 |
| 畜牧 `animal` | 500 | 解锁牧场、独角兽牧场，并开放数学、建筑等路径 |

矿井是矿工职业解锁链的一部分。让矿物稳定增长后，工坊工具与建筑才能连续推进。猎人则生产猫力，用猫力发动狩猎，取得毛皮、象牙等资源。

毛皮等非常见资源还能带来幸福度收益，但有些会持续消耗。不要只看狩猎后资源增加了多少，也看它能维持多久。

### 5.2 工坊的价值：让同一份劳动更有效率

工坊既提供合成相关加成，也开放升级。工具升级经常比单纯多建一个昂贵建筑更划算。

源码中的例子：

- 矿物锄头 `mineralHoes` 提供 `catnipJobRatio +0.5`，主要改善农民生产。
- 矿物斧头 `mineralAxes` 提供 `woodJobRatio +0.7`，主要改善伐木工生产。

这些效果有自己的适用范围。锄头并不等于把所有猫薄荷来源统一翻 1.5 倍，斧头也不是把所有木材获得方式都按同一个比例放大。

### 5.3 学会留原料，而不是一次全部加工

常见初始合成投入如下，产出数量可能受到合成加成影响：

| 产物 | 每次合成的基础投入 |
| --- | --- |
| 木梁 `beam` | 175 木材 |
| 石板 `slab` | 250 矿物 |
| 金属板 `plate` | 125 铁 |
| 钢 `steel` | 100 铁 + 100 煤 |
| 脚手架 `scaffold` | 50 木梁 |
| 船 `ship` | 25 星图 + 150 金属板 + 100 脚手架 |

合成木梁会消耗用于小屋、图书馆、工坊和燃料的木材；合成钢会占用铁和煤。每次先确定近期目标，再加工它需要的部分。资源快封顶时，把暂时多余的基础资源转成后续必需的加工品，可以减少溢出浪费。

**达到的目标：食物、木材、矿物能稳定供给，工具升级能跟上，材料加工不会把关键原料耗空。**

## 6. 第三阶段：学会解决“容量不够”

一个物品要求 500 科学，而你的上限是 250，单纯等待不会成功。需要先扩科学容量。木材、铁和其他资源也是同样的道理。

常用选择：

| 瓶颈 | 优先查看 |
| --- | --- |
| 食物或前期基础资源容量 | 谷仓 |
| 多种物资容量 | 仓库及相关升级 |
| 科学容量 | 图书馆、学院、天文台等科研建筑 |
| 中期大量物资容量 | 港口、船只相关仓储升级 |
| 需要的研究还没出现 | 科技前置条件和解锁链 |

本版本普通图书馆每座的基础科学容量贡献是 250，科研效率贡献为 10%；后面还有进一步修正。科研建筑可以同时解决科学“产得慢”和“存不下”两类问题，但仍需要学者或其他科学来源。

资源经常封顶时，可以优先检查有没有目标需要它、能否加工、是否该升级仓储；相应工人也可以临时调去解决别的短缺。

## 7. 第四阶段：冶炼、煤与工业供给

冶炼厂把木材、矿物转换为铁。它需要持续投入；造好以后原料不够，实际转换量就会下降。

扩工业时，按这条链检查：

```text
伐木工 / 矿工 → 木材与矿物净供给 → 开启的冶炼厂 → 铁
煤与铁 → 钢 → 更高级的建筑、工具与设备
```

每次增加转换设施后，看投入资源的净产出有没有转负。若木材持续下降，可以增加供给、研究工具，或减少开启的冶炼厂数量。后期能源也是同样的供需管理问题。

进入工业阶段还要留意污染及其相关效果。当前版本的“隐藏污染”选项只影响显示，不会取消污染机制。

## 8. 中期的三个主要增长方向

### 8.1 科学：用解锁改变资源来源

数学、建筑、工程、写作、哲学、天文学和航海等，会逐步打开学院、木屋、仓库、锯木厂、水渠、宗教、天文台、船只等体系。

不要只按科技费用从低到高全部研究。先看下一项目标需要什么：食物压力大时关心供给和需求，人口扩张时关心住房，科学封顶时关心容量，工业卡住时关心原料和转换效率。

天文事件出现时及时观测，逐步积累星图；星图与后面的船只、科研和太空发展有关。

### 8.2 贸易与船只：打开稀缺资源入口

贸易需要支付成本，也有不同种族、关系和随机收益。斑马贸易是中期获取钛的重要途径之一。

本地源码里，斑马钛掉落的基础概率为：

```text
0.15 + 船只数量 × 0.0035
```

船只还参与单次钛数量计算；关系和交易量等继续影响收益。这个例子说明，增加船只会同时改善多个环节。实际概率处理和交易限制以游戏逻辑为准，不应把公式算出的超 100% 数字理解成无限叠加的概率收益。

船只建造本身耗费星图和加工材料，因此应把稳定材料链、仓储、航海和贸易目标一起规划。

### 8.3 宗教：区分三层资源与重置

宗教中有几个名字相近、含义不同的概念：

| 概念 | 理解方式 |
| --- | --- |
| 信仰资源 `resources.faith` | 当前可积累、可支出的信仰，受容量限制 |
| 累计崇拜 `religion.faith` | 通过赞美太阳 `praise()` 等累计的量；与太阳革命收益有关 |
| 顿悟相关值 `faithRatio` | 由宗教重置积累，提升后续赞美的收益 |
| 超越等级 `transcendenceTier` | 更长期的宗教成长层级 |

赞美太阳会消耗当前信仰，增加累计崇拜。宗教重置 `resetFaith` 会牺牲累计崇拜来增加顿悟相关值；超越又会消耗一定顿悟来换取等级。它们的代价与回报不同。

早期先建立信仰来源、了解升级效果，围绕太阳革命逐步发展。不要因为出现了一个重置按钮就反复点击。做宗教重置或超越前，先手动备份，并确认会失去什么、下一轮收益来自哪里。

## 9. 太空、时间与挑战怎么推进

太空阶段从发射计划和行星探索展开，各星球设施提供新的资源与倍率。这时常见瓶颈是石油、钛、合金、星图、科学容量以及供能，而不是单一基础资源。

推进时先选择一项当前能形成有效生产链的目标，核对完整费用与后续设施，不必同时追逐所有新行星。能源不足和原料短缺都会限制某些设施的实际表现。

时间系统进一步引入时间水晶、时间设施和更长线的增长机制；挑战则会改变常规规则，并提供对应奖励。等普通发展链已经熟悉，再逐项尝试更容易理解效果。进入挑战前先确认重置内容并备份。

## 10. 什么时候转生

顶部“重置”是开始下一周目，和本地存档面板的“恢复备份”不同。转生会清理大量本轮建设和资源，换取部分长期成长。

本版本 `getResetPrestige()` 计算用于结算的猫咪数量。在普通条件下可先按实际人口理解：

- 超过 **35** 只时，开始有业相关收益。
- 超过 **70** 只时，新增领导力 `paragon` 为 `结算猫数 - 70`。
- 例如普通条件下 100 只猫，新增领导力为 30。

这里的领导力是长期资源，和村庄里任命一只猫当领袖不同；某些条件会改变用于结算的数量。真正转生前，以游戏的收益预览和确认说明为准。

首次游玩不必刚过 35 或 70 就立刻转生。可以比较：再增加一批人口是否还容易、是否快解锁关键设施、这一轮是否已经陷入很长的等待。第一次以推进到能取得一笔有用的长期奖励为目标即可，没有适合所有节奏的固定人口答案。

转生前建议：

1. 在右下角立即保存并备份，再导出一份文件。
2. 看清楚当前预计收益和本轮未完成的关键目标。
3. 确认宗教及其他长期系统的状态，不把原料或普通建筑误认为必然保留。
4. 如果有时间领域相关的保留设施，查看其具体规则；没有相应机制时，不指望普通库存完整进入下一轮。

本地版会在转生前额外保存，并在下一周目的数据成功写入磁盘后刷新。点顶部“删档”则开启新的空游戏，旧磁盘进度会保留一份操作前备份。

## 11. 挂机、本地运行和离线进度

**可以断网运行**，表示游戏文件和存档服务都在本机；它并不自动意味着关掉页面后照常生产。

本版本网页端的“启用离线进度” `enableRedshift` **默认关闭**，可在选项中开启。开启后由原版 `calculateRedshift` 等逻辑补算，受到容量、供给和系统规则限制，不等于完全重放每次点击和每个事件。

当前代码的补算时间上限为：普通早期 10 游戏年；年份达到 1000 或已有领导力时为 40 游戏年。长期离开前仍建议稳定粮食与工业投入，并安排合适的仓储。

本地服务器关闭后，不应继续在仍打开的页面里玩：页面可能暂时还能响应，但新进度无法正常写入磁盘。重新双击 `start.cmd` 启动服务，并按保存状态提示操作。

## 12. 卡住时按这个顺序排查

| 现象 | 先检查什么 | 可以采取的行动 |
| --- | --- | --- |
| 猫薄荷持续减少 | 季节、人口、农民、精炼操作 | 补农民、留口粮、控制扩人口 |
| 建筑显示可见但不能买 | 实际费用、各项资源容量 | 补原料或扩仓储；可见不等于买得起 |
| 科学一直不够 | 学者数量、科学净产出、上限 | 增加科学来源，扩图书馆等容量 |
| 建了冶炼厂却产铁慢 | 开启数量、木材和矿物供应 | 调整投入或减少开启数量 |
| 工人越来越多却效率不理想 | 幸福度、工具、岗位分配 | 补幸福来源和效率升级，重排分工 |
| 有住房却没有新猫 | 猫咪是否正在迁入、粮食状况 | 等待迁入并保证供给 |
| 想买的科技还没出现 | 前置科技和解锁链 | 查看已有科技的解锁说明 |
| 资源数量很高但不能升级 | 是否缺另一种材料或加工品 | 根据目标费用补齐短板 |
| 关闭页面后没有增加资源 | 离线进度是否开启 | 检查选项，理解补算上限 |
| 本地状态栏提示冲突 | 是否另开了游戏窗口 | 保留最新窗口，刷新旧窗口 |
| 保存失败 | 服务窗口是否仍运行、磁盘是否可写 | 先保留页面和已有备份，恢复服务后再保存 |

## 13. 一张便于照着玩的路线表

| 阶段 | 当前主要目标 | 能继续推进的信号 |
| --- | --- | --- |
| 开局 | 田地 → 木材 → 小屋 → 图书馆 | 有人口与科学来源，粮食有余量 |
| 生存稳定 | 历法 → 农业，安排农民和仓储 | 冬天能维持供给或靠库存安全度过 |
| 基础经济 | 采矿、射箭、畜牧，建立职业分工 | 木材、矿物、猫力都有用途和来源 |
| 工坊与冶炼 | 工具、加工材料、铁和煤 | 工业能持续运行，原料不会被抽空 |
| 中期扩展 | 科研容量、住房、幸福度、贸易、宗教 | 开始取得更强倍率与稀缺资源 |
| 高级发展 | 船只、钛、工业升级、太空设施 | 完成若干完整的高级生产链 |
| 多周目 | 评估收益后转生，购买长期升级 | 下一轮相同目标推进明显更顺畅 |

每个阶段留一个明确目标，通常就能看出该把下一只猫安排在哪个岗位，以及下一笔资源值得花在哪里。
